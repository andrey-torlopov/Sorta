## Настройки / Settings

RU: кнопка «Настройки» на главном экране открывает выбор темы (системная, светлая,
тёмная) и языка (Русский, English). Выбор сохраняется между запусками и применяется
сразу. Системные команды меню и части диалогов macOS могут сохранять язык системы.
В блоке автора доступна консольная версия PhotoSorterCLI: она использует то же
ядро обработки, но работает через Терминал macOS. Устанавливать CLI для Sorta не нужно.

EN: the Settings button on the main screen opens appearance choices (System,
Light, Dark) and language choices (Русский, English). Your selection is applied
immediately and persists between launches. System-owned menu commands and macOS
dialog controls may keep the system language. The developer section links to PhotoSorterCLI, which uses
the same processing engine through macOS Terminal. Sorta does not require the CLI.

# Данные, файлы и конфиденциальность

*[English](../en/data-and-privacy.md)*

Sorta обрабатывает файлы в выбранных вами папках на Mac. Приложение не импортирует коллекцию в собственную медиатеку и не отправляет фотографии разработчику. Учётная запись не нужна.

## Сохраняйте отдельную копию фотографий

Начните с копий небольшого набора характерных файлов. Оставьте **удаление после обработки выключенным**, а для первой сортировки — **включённую структуру папок** и отдельную папку назначения. Откройте результаты, проверьте имена, даты, изображение и место сохранения. Только после этого переходите к большой коллекции.

В Sorta нет встроенного резервного копирования или отмены уже выполненных файловых изменений. Остановка прекращает дальнейшую работу там, где операция поддерживает отмену; уже записанные, перемещённые или изменённые файлы она не восстанавливает. Сообщение об успехе не заменяет проверку результата и независимую резервную копию.

## Что операции меняют в файлах

| Операция | Влияние на файлы |
|---|---|
| Сортировка | По умолчанию копирует файлы; может переименовывать их и создавать папки по дате. Включение удаления оригиналов переключает обработку на перемещение. |
| Сортировка без структуры папок | Использует исходный каталог каждого файла. Этот режим **не** собирает плоскую коллекцию в выбранной папке назначения. |
| DNG → HEIC | Рекурсивно читает DNG и сохраняет HEIC в выбранной корневой папке. Структура исходных подпапок не воспроизводится. Опциональное удаление убирает исходник после успешной конвертации. |
| Исправление дат | Меняет даты файловой системы и атрибут даты создания содержимого. EXIF `DateTimeOriginal` не переписывается. Вручную выбранная дата применяется к выбранной операции. |

Конвертация не гарантирует сохранение всех свойств RAW и каждого поля метаданных. Проверяйте результат на файлах своей камеры и своего рабочего процесса. См. [подробности операций и ограничения](features.md).

## Что остаётся на Mac

| Данные | Назначение и срок хранения |
|---|---|
| Подтверждение первого знакомства | Сохраняется в локальных настройках после подтверждения информационного окна |
| Язык и тема | Сохраняются локально и восстанавливаются при следующем запуске |
| Выбранные папки, параметры и прогресс | Состояние текущего сеанса; приложение не ведёт постоянный каталог фотографий |
| Журнал операции | Сообщения в памяти, которые могут содержать имена, пути, даты и ошибки; автоматически не отправляются и не сохраняются как отчёт |
| Обработанные файлы | Записываются в места, определяемые операцией; управляются отдельно от настроек приложения |

При первом показе информационного окна кнопка подтверждения отсчитывает 30 секунд. Отметка о прочтении сохраняется только после нажатия доступной кнопки. Окно можно открыть снова через **Помощь → Важная информация**.

Смена языка интерфейса переводит и ранее появившиеся сообщения журнала. Она не переименовывает файлы, не меняет выбранную для операции дату и не перезапускает обработку.

## Доступ к папкам и внешние поставщики файлов

Выбирайте папки через системное окно macOS или область перетаскивания приложения. Для перетащенной папки может понадобиться подтверждение в системном окне. Sorta использует разрешение на выбранную папку; отсутствующий, отключённый или недоступный для записи каталог может помешать операции.

Доступные локальные файлы можно обрабатывать без интернета. Для файлов в iCloud Drive, на сетевом диске или у другого поставщика могут потребоваться сеть и предварительная загрузка. Синхронизация поставщика также может распространять изменения и удаления файлов. У Sorta нет собственной облачной синхронизации; правила поставщика действуют отдельно.

## Передача информации

В Sorta нет рекламы, аналитических SDK и автоматической отправки фотографий или журналов разработчику. Ссылки Boosty и GitHub открывают внешний браузер, ссылка поддержки — почтовое приложение. Эти сервисы обрабатывают данные по своим правилам.

Перед отправкой скриншота, фрагмента журнала или примера по возможности уберите личные имена, полные пути, геометки и личное содержимое изображения. Отправлять ли файл в поддержку, решаете вы. [Политика конфиденциальности](../../PRIVACY.md) описывает локальную обработку и добровольную переписку; [страница поддержки](../../SUPPORT.md) объясняет, какие сведения помогают разобраться в проблеме.

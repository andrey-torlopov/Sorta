# Быстрый старт

[English](../en/quick-start.md) · [Документация](index.md) · [Возможности](features.md) · [CLI](cli.md)

Инструкция описывает текущие исходники Sorta для **Mac с Apple Silicon и macOS 15.1 или новее**. Доступность приложения указана в [статусе выпуска](releases.md). Для разработчиков есть [инструкция по запуску исходников](development.md).

## 1. Подготовьте небольшой набор копий

Скопируйте несколько характерных фотографий в отдельную тестовую папку. Для первой сортировки подойдут JPG, PNG и HEIC; DNG проверяйте отдельно в конвертере. Основной архив и его резервную копию храните вне рабочей папки.

Создайте пустую целевую папку вне тестового источника. Так результат первого запуска будет проще проверить, а при повторной обработке прежний результат не попадёт в список исходных файлов.

## 2. Прочитайте важную информацию

При первом запуске Sorta показывает обязательное информационное окно. На кнопке **«Закрыть»** идёт отсчёт; она станет доступна через **30 секунд**. Прочитайте текст и нажмите кнопку — окончание отсчёта само по себе не подтверждает прочтение.

Открыть этот экран повторно можно через **«Помощь → Важная информация»**. После первого подтверждения кнопка закрытия при повторном просмотре доступна сразу.

## 3. Выберите источник

На главном экране нажмите **«Выберите папку источника»** и укажите тестовую папку. Можно также перетащить папку в область выбора. Если macOS запросит подтверждение доступа, выберите её в системном диалоге.

Обработка включает поддерживаемые файлы во вложенных папках. Символические ссылки пропускаются. После выбора источника доступны три действия:

| Действие | С какими файлами работает |
|---|---|
| **«Сортировка фото»** | Исходная папка и отдельно выбранная целевая папка. |
| **«Конвертация DNG → HEIC»** | DNG в выбранной папке и её подпапках; результат HEIC помещается в выбранную корневую папку. |
| **«Исправление дат»** | Поддерживаемые медиафайлы в выбранной папке и её подпапках; даты меняются там же. |

## 4. Попробуйте сортировку с сохранением оригиналов

Выберите **«Сортировка фото»**, нажмите **«Выберите целевую папку»** и укажите пустую папку назначения.

Для первого запуска оставьте **«Создать структуру папок в папке назначения»** включённым, а **«Удалить после обработки»** — выключенным. Проверьте настройки **«Переименовать файлы в формат даты»** и **«Исправить метаданные (даты создания/изменения)»** с учётом нужного результата, затем нажмите **«Старт»**.

При включённой структуре результат размещается внутри цели в `Photos/Год/Месяц` и `Videos/Год/Месяц`. Удаление по умолчанию выключено: сортировка копирует файлы. Поведение при отключённой структуре описано в [возможностях](features.md).

## 5. Проверьте результат

Прочитайте сообщения обработки, откройте несколько полученных файлов, сравните изображение, имена и даты с тестовыми источниками. Оставьте **«Удалить после обработки»** выключенным, пока результат не будет вас устраивать и вы не проверите резервную копию. Только после этого переходите к большему набору.

Чтобы остановить обработку, нажмите **«Отмена»**. Sorta может сначала закончить текущий файл; дождитесь итогового состояния. Уже выполненные изменения сохраняются. После завершения кнопка **«На главный»** возвращает к выбору источника.

При конвертации DNG сохраняйте исходники и сравнивайте HEIC с RAW. HEIC использует сжатие с потерями и не сохраняет возможности дальнейшей обработки DNG. Действие **«Исправление дат»** меняет файлы в выбранной рабочей папке, поэтому для него тоже используйте копии.

## 6. Выберите язык и оформление

Откройте **«Настройки»** на главном экране или нажмите **Command-,**. Доступны темы **«Система»**, **«Светлая»**, **«Тёмная»** и языки **Русский**, **English**. Выбор применяется сразу и сохраняется между запусками.

Язык меняется и в уже открытых окнах приложения, и в существующих сообщениях обработки. Выбранные папки, опции и выполняющаяся задача сохраняются. Системные пункты меню и элементы диалогов выбора файлов используют язык macOS.

Дополнительная справка доступна в **«Помощь → Справка Sorta»**, а также на страницах [данные и конфиденциальность](data-and-privacy.md) и [поддержка](../../SUPPORT.md).

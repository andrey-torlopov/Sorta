# Консольная версия

[English](../en/cli.md) · [Документация](index.md) · [Быстрый старт](quick-start.md) · [Возможности GUI](features.md)

[PhotoSorterCLI](https://github.com/andrey-torlopov/PhotoSorterCLI) предоставляет интерактивные инструменты для фотографий в Терминале macOS. Он использует общее с Sorta ядро [PhotoSorterCore](https://github.com/andrey-torlopov/PhotoSorterCore) и устанавливается отдельно. Для работы Sorta CLI не нужен.

В GUI три карточки действий. В меню CLI шесть операций, включая преобразование PNG и сверку имени с датой — отдельных действий для них в GUI нет. Команды, языковые параметры и правила ввода ниже относятся к **подготовленному кандидату CLI 0.2.0**.

## Требования и доступность

CLI требует **macOS 15.0 или новее**; первый подготовленный установочный пакет предназначен для **Apple Silicon (arm64)**. Для графического приложения Sorta требуется macOS 15.1+.

На **14 ноября 2026 года** публичная ветка CLI `main` ещё содержит **0.1.0**. Подготовлен подписанный пакет **0.2.0**, но публикация его исходников/тега, нотариализация и публичный выпуск пакета пока не завершены. Проверяйте сведения о публикации в [репозитории CLI](https://github.com/andrey-torlopov/PhotoSorterCLI) и [статусе выпуска](releases.md). Наличие текущих публичных исходников не означает поддержку описанных здесь параметров и безопасных значений ввода версии 0.2.0.

## Запуск CLI 0.2.0 после публикации

Сначала убедитесь, что **версия 0.2.0 или новее действительно опубликована**, затем используйте инструкцию по установке или сборке именно этой версии. Для более старой копии нужна соответствующая ей документация. После получения 0.2.0 следующие команды проверяют версию/справку и открывают русский интерфейс:

```sh
photos-sorter-cli --version
photos-sorter-cli --help
photos-sorter-cli --language ru
```

Последняя команда открывает интерактивное меню. Выберите номер, затем введите запрошенные пути и настройки. Это интерактивный интерфейс: названия операций и пути к фотографиям не передаются как подкоманды командной строки.

Установочный пакет предназначен для размещения исполняемого файла в `/usr/local/bin/photos-sorter-cli`. Для установленного пакета Xcode не требуется; условия сборки из исходников описаны в репозитории CLI.

## Шесть операций

| Номер | Действие меню | Результат |
|---|---|---|
| 1 | Конвертировать DNG в HEIC | Преобразует DNG; удаление источников доступно отдельно и по умолчанию выключено. |
| 2 | Разложить файлы по Photos(Videos)/Год/Месяц | Копирует или перемещает поддерживаемые медиафайлы с настройками переименования по дате и исправления дат. |
| 3 | Исправить даты файлов | Обновляет файловые атрибуты дат поддерживаемых медиафайлов по доступным сведениям. |
| 4 | Установить заданную дату файлов | Применяет введённую дату к файловым атрибутам поддерживаемых медиафайлов. |
| 5 | Сверить даты в именах файлов с метаданными | Выводит несовпадения имени и даты, не изменяя проверяемые файлы. |
| 6 | Конвертировать PNG в HEIC | Преобразует PNG с таким же необязательным удалением источников, как у DNG. |

Пункт **0** завершает работу в меню. Просмотр папок включает подпапки. Конвертация DNG/PNG собирает результат в выбранной корневой папке. Сортировка использует дерево назначения при включённом создании структуры; без него применяется исходный каталог каждого файла. Общие границы работы с датами и форматами описаны в [возможностях GUI](features.md).

## Язык и ввод в 0.2.0

Укажите `--language ru` или `--language en`; `--lang` — сокращённый вариант. Выбор действует для этого запуска и не сохраняется. Язык CLI не зависит от настроек Sorta.

Без флага используется первое непустое значение из `LC_ALL`, `LC_MESSAGES`, затем `LANG`. Поддерживаются русский и английский; при явно заданной неподдерживаемой локали используется английский. Если переменных нет, CLI проверяет поддерживаемые языки macOS, затем выбирает английский.

В обоих интерфейсах принимаются `да`/`нет`, `д`/`н`, `yes`/`no` и `y`/`n`. Enter выбирает показанное значение по умолчанию; для удаления это **«Нет»**. В диалоге ввода **Ctrl-D** отменяет незавершённый ввод и завершает программу. `--help` и `--version` только выводят информацию и не обрабатывают фотографии.

## Работайте с копиями

Начните с небольшой выборки и оставьте удаление выключенным. Перед подтверждением сортировки проверьте сводку настроек. Операции с датами меняют выбранные файлы на месте, а HEIC использует сжатие с потерями. Отмена или выход из программы не восстанавливают уже выполненные изменения.

Прежде чем переходить ко всему архиву, проверьте результат, даты и сообщения об ошибках. По вопросам работы используйте [поддержку](../../SUPPORT.md) и документацию репозитория CLI.

# Разработка и архитектура

*[English](../en/development.md)*

Sorta — нативное приложение SwiftUI/AppKit для **macOS 15.1 и новее**. Первая поставка рассчитана на **Apple Silicon (arm64)**. Нужен Xcode со Swift 6 и SDK, поддерживающим заданную минимальную версию системы. Наличие параметра архитектуры в скрипте само по себе не подтверждает поддержку Intel.

## Открытие и сборка проекта

```sh
git clone https://github.com/andrey-torlopov/Sorta.git
cd Sorta
open MacosApp.xcodeproj
```

Выберите общую схему **MacosApp** и **My Mac**. Имя продукта — **Sorta**. Корень репозитория — каталог с `MacosApp.xcodeproj`; команды ниже выполняются в нём.

GUI использует удалённый Swift-пакет [PhotoSorterCore](https://github.com/andrey-torlopov/PhotoSorterCore), закреплённый **ровно на 0.0.2**, revision `6b97352c15a956d633493bee955037d73757a304`. Требование проекта и отслеживаемый `MacosApp.xcodeproj/project.xcworkspace/xcshareddata/swiftpm/Package.resolved` должны соответствовать друг другу. При первой загрузке зависимости нужен доступ к GitHub. Отдельно установленный CLI не является зависимостью GUI.

Локальная Debug-сборка arm64 с подписью ad-hoc:

```sh
xcodebuild \
  -project MacosApp.xcodeproj \
  -scheme MacosApp \
  -configuration Debug \
  -destination 'platform=macOS,arch=arm64' \
  -derivedDataPath build/LocalDebug \
  -clonedSourcePackagesDirPath build/SourcePackages \
  -onlyUsePackageVersionsFromResolvedFile \
  -disableAutomaticPackageResolution \
  CODE_SIGN_IDENTITY=- CODE_SIGNING_REQUIRED=NO \
  CODE_SIGN_STYLE=Manual DEVELOPMENT_TEAM= \
  build
```

Запускайте через Xcode или открывайте `.app` через Finder/LaunchServices. Локальная подпись ad-hoc нужна для разработки и не создаёт дистрибутив App Store. Сертификаты, provisioning profiles, учётные данные и архивы выпусков не входят в репозиторий исходников.

## Карта кода

| Расположение | Ответственность |
|---|---|
| `MacosApp/MacosAppApp.swift` | Сборка зависимостей приложения, время жизни окон, общие настройки и команды |
| `MacosApp/Modules/SortPhotos/`, `ConvertDngToHeic/`, `FixDates/` | Экраны и состояние конкретных операций; вызовы Core |
| `MacosApp/Modules/Onboarding/` | Подтверждение первого знакомства и монотонный отсчёт 30 секунд |
| `MacosApp/Modules/Settings/`, `About/`, `MacosApp/Help/` | Дополнительные окна и их содержимое |
| `MacosApp/Core/` | Выбор и доступ к папкам, время жизни операций, локализация и настройки представления |
| `MacosApp/Design/` | Общие элементы интерфейса, типизированный журнал, общий блок автора |
| `MacosApp/Resources/` | Каталог строк RU/EN, локализованная справка, иконки/аватар, privacy manifest и acknowledgements |
| `MacosAppTests/`, `MacosAppUITests/` | Unit- и UI-тесты |
| `scripts/` | Поэтапные команды выпуска и проверка Mach-O/содержимого приложения |

Папки фич организуют код внутри app target; это не отдельные SwiftPM-пакеты. **PhotoSorterCore** владеет общими алгоритмами обработки файлов. GUI отвечает за выбор доступа, взаимодействие с пользователем, локализованное представление и время жизни операций. Его папка `Core/` содержит вспомогательный код приложения и не является внешним пакетом.

## Состояние и конкурентность

Один наблюдаемый `AppPreferences` передаёт язык и тему корневым представлениям окон. UserDefaults хранит эти настройки и подтверждение первого знакомства. Смена языка или темы обновляет существующие окна без пересоздания корней, сброса выбранных папок или перезапуска операции. Команды меню и элементы диалогов, которыми управляет AppKit, могут оставаться на языке macOS.

`PhotoOperationSession` владеет состоянием и отменой каждой операции. События связаны с активной операцией; завершение учитывает окончание рабочей задачи и обработку накопленных событий. Блокирующие проверки папок и синхронное исправление дат выполняются на отдельных акторах, а не на UI-акторе. Запрос отмены не восстанавливает уже изменённые файлы.

Записи журнала хранят типизированные ключи локализации, аргументы и время до момента отображения. Преобразуйте события Core в сообщения GUI, а не сохраняйте готовую английскую строку. Пути, пользовательский ввод и технические значения сохраняйте без перевода. Новые строки должны иметь русский и английский варианты, включая ошибки и дополнительные окна.

## Файлы и конфиденциальность

Sandbox разрешает чтение и запись для выбранных пользователем файлов. Балансируйте security-scoped доступ, проверяйте доступность назначения и запрашивайте подтверждение перетаскивания, если система ещё не выдала разрешение. Постоянный каталог фотографий и текущий выбор папок приложение не сохраняет.

Не выводите поведение только из названия элемента интерфейса: сортировка без структуры использует исходные каталоги, конвертация DNG пишет в выбранный корень, исправление дат меняет даты файловой системы/создания содержимого, а не EXIF `DateTimeOriginal`. Изменения этих контрактов отражайте в [описании функций](features.md) и [работы с данными](data-and-privacy.md).

Privacy manifest описывает использование API локальных настроек и временных меток файлов. При изменении обработки данных обновляйте и manifest, и [политику конфиденциальности](../../PRIVACY.md).

## Проверки

Локальный запуск unit target без UI-набора:

```sh
xcodebuild \
  -project MacosApp.xcodeproj \
  -scheme MacosApp \
  -configuration Debug \
  -destination 'platform=macOS,arch=arm64' \
  -derivedDataPath build/UnitTests \
  -clonedSourcePackagesDirPath build/SourcePackages \
  -onlyUsePackageVersionsFromResolvedFile \
  -disableAutomaticPackageResolution \
  -parallel-testing-enabled NO \
  -only-testing:MacosAppTests \
  CODE_SIGN_IDENTITY=- CODE_SIGNING_REQUIRED=NO \
  CODE_SIGN_STYLE=Manual DEVELOPMENT_TEAM= \
  test
```

Тесты покрывают онбординг, настройки, локализацию, ссылки, выбор и доступ к папкам, отмену и время жизни операций. У Core есть собственный набор тестов в его репозитории. Для файловых проверок используйте синтетические или обезличенные копии; не добавляйте личные фотографии и журналы с частными путями в Git.

Вручную проверяйте первый запуск, повторное открытие информации, доступ к папкам, оба языка и темы, активную операцию при смене представления, отмену и Settings после закрытия главного окна. Локальный тест не подтверждает работу на минимальной ОС, Intel, внешнем диске, у поставщика файлов, после чистой установки или обновления. См. [зафиксированные проверки](releases.md) и отдельные этапы поставки в [инструкции выпуска](../release.md).

Для GUI не назначена общая открытая лицензия. Публичный доступ к исходникам сам по себе не предоставляет лицензию. PhotoSorterCore декларирует MIT; его уведомление включено в [Acknowledgements.txt](../../MacosApp/Resources/Acknowledgements.txt).

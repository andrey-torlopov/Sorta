# Sorta

## Зачем нужна Sorta

Фотоархив растёт с каждой поездкой, сменой телефона и новой скопированной папкой. Со временем снимки оказываются в разных каталогах, а даты файлов перестают складываться в понятную историю.

Sorta помогает привести архив в порядок на Mac: разложить поддерживаемые фотографии и видео по датам, конвертировать DNG в HEIC, исправить или задать даты файлов. Вы выбираете папки и параметры; обработка выполняется локально, без аккаунта приложения.

Фотографии важнее аккуратных каталогов. Сначала попробуйте на небольшом наборе **копий**, проверьте результат и сохраните резервную копию оригиналов.

## Доступность

- **macOS 15.1 и новее**, **Apple Silicon**. Sorta — приложение для Mac, не для iPhone или iPad.
- Интерфейс и документация **на русском и английском**. Язык приложения переключается в настройках.
- **Системная, светлая и тёмная** темы. Выбор сохраняется между запусками.
- Исходники опубликованы. Готовится **бесплатный выпуск в Mac App Store**; публичный репозиторий не означает доступность приложения в магазине.

## Начните с небольшой копии

1. Сделайте небольшую тестовую копию фотографий и подготовьте пустую папку для результата.
2. Прочитайте информацию при первом запуске. Кнопка **«Закрыть»** станет доступна через 30 секунд; этот же текст есть в меню **«Помощь → Важная информация»**.
3. Выберите тестовую папку, откройте **«Сортировка фото»** и укажите папку назначения.
4. Оставьте **«Создать структуру папок в папке назначения»** включённым, а **«Удалить после обработки»** — выключенным. Проверьте параметры переименования и изменения дат файлов.
5. Запустите обработку. Откройте результат, проверьте имена и даты, убедитесь, что оригиналы сохранились. Только после этого переходите к архиву, сохранив его резервную копию.

Если отключить создание структуры папок, используются исходные каталоги файлов, а не плоское копирование в выбранную папку назначения. Инструменты дат меняют атрибуты файлов, а не все поля EXIF внутри снимков. [Быстрый старт и подробности операций →](Docs/ru/quick-start.md)

## Что есть в приложении

| Для фотографий | Для удобства работы |
|---|---|
| Сортировка поддерживаемых фото и видео по годам и месяцам | Выбор папок и перетаскивание |
| Переименование файлов по дате при необходимости | Прогресс, журнал операций и отмена |
| Конвертация DNG → HEIC | Напоминание проверить копии перед массовой обработкой |
| Исправление дат файлов и установка своей даты | RU/EN и системная, светлая, тёмная темы |
| Общее ядро обработки с консольной версией | Локальная обработка, без аккаунта приложения |

Конвертация не заменяет резервную копию. Перед удалением оригиналов проверьте качество изображений и метаданные. Форматы, расположение результатов и работа с датами описаны в [возможностях и ограничениях](Docs/ru/features.md).

## Удобнее в Терминале?

[PhotoSorterCLI](https://github.com/andrey-torlopov/PhotoSorterCLI) использует то же ядро [PhotoSorterCore](https://github.com/andrey-torlopov/PhotoSorterCore) через Терминал macOS. В CLI также доступны конвертация PNG → HEIC и проверка соответствия дат именам файлов. Подготовленная версия **0.2.0** добавляет RU/EN; эти команды относятся к ней и пригодятся после её публикации:

```sh
photos-sorter-cli --language ru
photos-sorter-cli --language en
```

CLI — отдельная программа; для работы Sorta она не нужна. Новый CLI-пакет ещё проходит подготовку к выпуску. [Руководство CLI и статус распространения →](Docs/ru/cli.md)
